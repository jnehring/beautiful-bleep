# Macros

## Introduction

The 16 automatable controls of the *Bleep Patch* plugin in Live. Automate them
in Live and use them anywhere on the board.

## How does it work?

*Macro 1–16* are control outputs between 0 and 1, following the plugin's
parameters in Live. Patch a macro to any input, with an amount, to make one
knob in Live move several things. Macros exist only in the plugin.

## How to use it?

Patch *Macro 1* to a filter's cutoff and a reverb's mix, then automate or map
that one knob in Live.

## Reference

| Output | Signal | What it does |
|---|---|---|
| Macro 1–16 | control | The plugin's macro values, 0–1 |
