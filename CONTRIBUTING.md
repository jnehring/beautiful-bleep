# Contributing to Bleep Patch

Thanks for helping.

## Contributor License Agreement

Before we can merge your first contribution you must agree to the
[CLA](CLA.md). Add this sentence to your first pull request:

> I agree to the Bleep Patch CLA.

You keep the copyright in your work. The CLA lets the project change its
licence or its exceptions later, always staying open source.

If you contribute on behalf of an employer, make sure they agree too.

## Licences of contributions

Bleep is GPL-3.0-only with a module exception ([plain terms](website/content/developers/modules/licensing.md)). Your contribution is licensed as the part of the repository it goes into
(see the `LICENSE` file there and the SPDX header of each source file).

## Other

Run `python3 scripts/check/check-repo.py` before opening a pull request.
