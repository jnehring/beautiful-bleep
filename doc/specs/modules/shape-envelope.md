# Contour

Type id `shape-env` · category *Modulation* · colour proposal `#fda4af`

## 1. Purpose

An envelope and LFO that plays shapes from a library instead of computing
them from a few stages: 96 factory shapes (percussive decays, swells, bounces,
stairs, rhythmic gates, classic and unusual LFO waves) plus 8 shapes you draw
yourself. *Shape* picks one, *Morph* blends it into its neighbour, *Time* sets
how long it takes. Triggered it's a one-shot envelope, gated it holds at the
shape's sustain point, looped it's an LFO.

*ADSR*, *Function* and *Segments* build shapes from stages and curves; Shape
Env plays any contour at all, including ones that no stage model can reach
(echo bounces, stutters, irregular gates), and makes them easy to find by
browsing rather than by setting up.

## 2. Jacks

**Inputs**

| Jack | Type | What it does |
|---|---|---|
| Trig | `trigger` | Starts the shape from the beginning (4.3). |
| Gate | `gate` | Rising edge starts the shape; it holds at the sustain point while high; falling edge plays the rest. |
| Velocity | `control` (unipolar) | Scales the output through *Vel Amount*. Unpatched counts as 1. Sampled at each start. |

Every knob is also an input (`specs.md` section 7.3).

**Outputs**

| Jack | Type | What it carries |
|---|---|---|
| Out | `control` (unipolar 0…1; bipolar for shapes marked bipolar, see 4.1) | The shape. |
| Inv | `control` | `1 − Out` (unipolar) or `−Out` (bipolar). |
| Phase | `control` (unipolar) | Playback position 0…1, a ramp that other modules can use. |
| End | `trigger` | A pulse when the shape finishes (one-shot) or wraps (Loop). |
| Active | `gate` | High while the shape plays (one-shot and gated). For *Voice Out › Active*. |

## 3. Controls

**Knobs** (modulatable floats)

| Knob | Range | Default | What it does |
|---|---|---|---|
| Time | 1 ms – 60 s (exponential, centre 500 ms) | 500 ms | Duration of the whole shape (or one LFO cycle). A note value with *Sync*. |
| Shape | 0 – 103 (a stepped choice of the shape names, with the family names as headings) | 0 (Click) | Which shape plays: 0–95 factory, 96–103 user. |
| Morph | 0–100 % | 0 % | Blend toward the next shape in the library (4.2). |
| Level | 0–100 % | 100 % | Output scale. |
| Vel Amount | 0–100 % | 0 % | Peak scale `1 − VelAmount × (1 − Velocity)`, as in *ADSR*. |
| Skew | −1 … +1 | 0 | Time warp: + plays the start faster and the end slower, − the other way (4.4). |

**Settings**

| Setting | Values | Default |
|---|---|---|
| Mode | One-shot, Gated, Loop | One-shot |
| Sync | Off, 16 bars … 1/32T (the shared note values, straight, dotted, triplet) | Off |
| Reverse | Off, On | Off |
| Retrigger (shown in One-shot and Gated) | Restart, Ignore while running | Restart |

## 4. Behaviour

### 4.1 Shapes

A shape is a table of 256 points (values 0…1, or −1…+1 for bipolar ones),
read with linear interpolation at `phase × 255`. Each shape also has:

- a **sustain point** (a phase, or none) used in *Gated* mode;
- a **kind**: *envelope* (starts and ends at 0) or *cycle* (end equals start,
  so it loops without a jump);
- a **polarity** (unipolar or bipolar; envelopes are unipolar).

Factory shapes are generated by code at start-up from formulas, not stored as
data, so every machine has the same tables. They are numbered once and never
reordered; new factory shapes are added only after a library version change
that maps old indices, so saved boards keep their sound.

| # | Family | Kind | The eight shapes |
|---|---|---|---|
| 0–7 | Decays | envelope | Click, Snap, Short exp, Long exp, Linear, Log, Reverse-curve, Two-rate (fast then slow) |
| 8–15 | Plucks | envelope | Attack/decay at 1:20, 1:8, 1:4, 1:2, with soft and hard knees |
| 16–23 | Swells | envelope | Slow rise and quick drop, S-curve rise, rise-and-hold-and-drop, crescendo with dip, … |
| 24–31 | Sustains | envelope (sustain point) | ADSR-like with sustain at 25/50/75 %, AHDSR, overshoot-and-settle, double-attack, organ, pad |
| 32–39 | Bounces | envelope | Decaying bounces (3, 5, 8 hits), echoes at 1/8 spacing, ping-pong decays, stutter, flam, roll |
| 40–47 | Stairs | envelope | Rising and falling 3, 4, 6, 8 steps, alternating stairs |
| 48–55 | Classic waves | cycle, bipolar | Sine, Triangle, Saw up, Saw down, Square, Trapezoid, Half-sine, Exp saw |
| 56–63 | Skewed waves | cycle, bipolar | Sine and triangle skewed 10/25/75/90 % |
| 64–71 | Harmonic waves | cycle, bipolar | Sine + 2nd, + 3rd, + 2nd + 3rd, odd series, even series, octave pulse, formant, pinched sine |
| 72–79 | Gates | cycle, unipolar | Rhythmic gate patterns of 8 and 16 sub-steps, soft-edged (2 % ramps), e.g. x.x.xx.x |
| 80–87 | Wobbles | cycle, bipolar | Wobble, double wobble, swing wobble, sine with notch, bounce loop, heartbeat, breathing, sway |
| 88–95 | Textures | cycle, bipolar | Smoothed seeded noise curves (fixed seeds 1–8): irregular but repeating |
| 96–103 | User 1–8 | per drawing | Drawn in the view (5), saved in node data (6) |

(Full formulas live in `patch/common/dsp/Shapes.h`, `dsp::ShapeLibrary`; this
table names the families and order. Its tests pin a checksum per table, and the
module's test pins one over the whole library.)

### 4.2 Morph

`out = lerp(table[S], table[S + 1], Morph)` per point, with `S` = *Shape*
(rounded) and `S + 1` wrapping from 103 to 0. Because neighbours are related
within a family, *Morph* moves smoothly, e.g. Short exp → Long exp. Across a
family boundary it blends unlike shapes, which is allowed and often useful.
The sustain point and kind come from shape S while Morph < 50 %, from S + 1
above. *Shape* changes are picked up at the next start (one-shot, gated) or
crossfaded over 5 ms (Loop), so modulating it never clicks; *Morph* is read
per sample.

### 4.3 Modes and timing

- **One-shot:** Trig or a Gate rising edge plays the whole shape over *Time*,
  then *End* fires and the output stays at the last value (0 for envelopes).
  Before the first start the output is 0.
  *Retrigger* = *Restart*: a new start crossfades from the current level into
  the shape over 2 ms. *Ignore*: starts while running are dropped.
- **Gated:** as One-shot, but playback stops at the sustain point while
  Gate is high and continues on the falling edge. A gate that falls before
  the sustain point plays on without stopping. Shapes without a sustain point
  play as One-shot. Trig starts the shape like a gate of zero length.
- **Loop:** the shape repeats every *Time*; *End* fires at each wrap. Trig or
  a Gate rising edge resets the phase to 0 (crossfaded over 2 ms). Envelope
  shapes loop too (a repeating decay is a classic rhythmic effect). *Active*
  is always high in Loop.
- **Sync:** *Time* becomes a note value. In *Loop* with the transport playing,
  `phase = frac(ppq / beats)`, locked to bars, identical on every render and
  after loop jumps; Trig and Gate don't move the phase then (they still set
  the velocity). In One-shot and Gated, Sync only sets the duration.
- **Reverse** reads the table from the end (`1 − phase`); sustain points are
  mirrored too. Order: the playback phase is skewed (4.4), then reversed,
  then looked up, so Skew always speeds up the start of the playback. The
  Gated hold happens at the playback phase `target^(2^Skew)` with
  `target` = sustain (or `1 − sustain` reversed), which the skew maps back
  onto the sustain point.

### 4.4 Skew

Skew warps time before the table lookup: `phase' = phase^(2^(−Skew))`. At
+1 the first half of the shape takes a quarter of *Time*; at −1 about 71 %
(`√½`). It's the same for every shape, so it gives any library entry a
snappier or lazier feel without editing it.

### 4.5 Edge cases

- *Time* below 1 ms is clamped. Loop at short times reaches audio rate (up to
  1 kHz) without band-limiting; acceptable for modulation.
- An empty user slot (never drawn) holds a flat 0 line, marked "empty" in the
  browser.
- Inside a Voice Cell, each voice runs its own playback; the user tables are
  shared (node data is per node, not per voice).

- The **preview** draws the current (morphed, skewed) shape with the sustain
  point marked and a dot at the live phase.
- **Browse** opens a grid of thumbnails grouped by family; hovering a
  thumbnail previews it in the main graph; clicking sets *Shape* (one undo
  step). Left/right arrow keys step through shapes.
- **Draw** turns the preview into an editor for the current user slot (or
  offers *Copy to User n* when a factory shape is selected; it copies the
  shape as shown, with Morph, Skew and Reverse): *Free* drawing, a *Line*
  tool, a *Sustain* tool (click to place; *No sustain* removes it), *Smooth*,
  *Mirror* (make it symmetric), *Snap 8/16* (steps), *Envelope/Cycle* and
  *± Bipolar* toggles and *Clear*. A stroke is one undo step (`beginGesture`).

## 6. Saved state

Knobs and settings are params; the user shapes are node data:

```json
{
  "type": "shape-env",
  "params": { "time": 0.47, "shape": 0.0, "morph": 0.0, … },
  "data": {
    "user": [
      { "points": [0.0, 0.12, …], "sustain": 0.5, "kind": "envelope", "bipolar": false },
      … 8 entries (null for an empty slot) …
    ]
  }
}
```

`points` holds 64 values (3 decimals); they are resampled to 256 with a
monotone cubic on load, which keeps documents small. `sanitiseData` pads to 8
slots, resamples any other point count linearly to 64, replaces non-numbers
with 0, clamps points to the polarity's range, forces the last point to the
first for cycles, and drops a sustain point outside 0…1 (`patch::UserSlot`,
tested in the module's DSP test). `sustain` is `null` without one.

## 7. Engine requirements

- Node data and `setData` (as for the Step Sequencer); the user tables are
  built on the message thread and swapped in through a try-lock.
- `ShapeLibrary` in `patch/common/dsp/Shapes.h` (done; built in `prepare()`).
- Dotted/triplet note values up to 16 bars in `Tempo.h` (done).
- `ParamSpec::choiceGroups` for the family headings of the Shape choices (done).
- `liveValues`: `phase`, `holding`, `playing` (the latched shape), `sustain`
  (the hold point in playback phase, −1 for none) and `bipolar` for the
  preview. `liveArrays`: `preview` (128 points of the current morphed, skewed,
  reversed shape) every update, and `thumbs` (all 104 shapes × 48 points) once
  after the view sends the command `thumbs` (and after new data).

## 8. Tests

- Every factory shape: 256 finite points in range; envelopes start and end at 0; cycles end where they start.
- Library order is stable: a checksum of each table index is pinned in the test, so reordering fails.
- Morph 0 / 100 % equal shape S / S + 1; 50 % is their average.
- One-shot timing: *End* fires at exactly *Time*; Gated holds at the sustain point until the gate falls.
- Retrigger Restart: no step larger than a 2 ms crossfade allows; Ignore drops starts while running.
- Loop + Sync + transport: `phase = frac(ppq / beats)`; identical after a loop jump.
- Skew ±1 and Reverse map phases as documented.
- User shapes round-trip through the document; broken data loads safely; an empty slot outputs 0.
- The demo types file includes the module (`patch.ui-types`).

## 9. Later

- Shape packs: import and export user shapes as files, shared between boards.
- A 2D morph (two Morph knobs over a 4-shape square).
- Per-shape recommended *Time*, so browsing an LFO shape sets a sensible rate.
- Capture: record a control input into a user slot over *Time*.
