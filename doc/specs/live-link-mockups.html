Bleep Live Link: interface mockups

Two surfaces: the Max for Live device in Ableton Live, and the Live Params node on the board. These are design sketches, not screenshots. The device's logic is in live-link.js and tested outside Max; everything that shows a Live parameter's name or items on the board needs the device to send that back, which is not built.

1. In Live: the Bleep Live Link device Max for Live

One device = one channel = four rows. Each row has a Map button that doubles as its status line, the state of a discrete parameter, and a × to let go of it. The board decides every value; the device only writes it and reports what each row is mapped to. A row works out by itself whether it was mapped to a continuous parameter (a dial) or a discrete one (a switch or a menu).

2. On the board: the Live Params node Beautiful Bleep

A node has a Channel and four rows. Each row is a knob that cables can feed (a CV 1 to 4 input jack on the node adds to it, or drag a cable onto the knob), with a Min and a Max that scale it into part of a continuous parameter's range. The node's view shows what the device on the channel has mapped each row to. When you map a row, its knob jumps to the parameter's position, so nothing jumps in Live. This is a sketch of the view that is built (it was checked in a browser with a made-up state). A continuous row has a slider with two handles for Min and Max (circle and square), the row's value as a triangle inside the span, and a line where the row is asking the parameter to be right now.

How the pieces fit

You doWhat happens
Press Map in the device and click a parameterthe device reads its position, holds it there, and tells the board its name, kind, range and choices
(nothing)the board moves the row's knob to that position: the parameter does not jump
Cable an LFO onto the row's knobthe board sends knob + cable, scaled into Min..Max for a dial; the device writes it
Delete the node, or change its channelthe board sends -1; the device puts the parameter back where it was
Press × on a rowthe device puts the parameter back and tells the board the row is not mapped
