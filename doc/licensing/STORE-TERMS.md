# Bleep Patch Store: Developer Terms (draft outline)

These terms apply only to modules listed in the Bleep Patch Store. The
Module Exception in the core licence lets anyone publish modules, including
closed-source and paid ones, elsewhere without these terms.

## 1. Listing

- The developer owns their module and licenses it to buyers under the terms
  they declare on the listing (open source, freeware or proprietary EULA).
- Every listing must state its licence and link to its terms.
- Modules must use only the public Module API. Modules that copy core code
  must be GPL-3.0 and must say so.

- Jan Nehring processes payments and pays out to the developer after a

- Payout schedule, minimum threshold, taxes and refunds: <to be defined>.
- Developers set their own price. Free listings are always allowed.

## 3. Quality and safety

- Modules are reviewed for malware, crashes at load, undeclared network
  access and misleading metadata.
- Listings may be removed for breaching these terms, infringing others'
  rights or being unsafe.

## 4. Distribution rights

- The developer grants Jan Nehring the right to host, distribute and display
  the module and its listing to buyers.
- Updates must remain compatible with the declared API version, or
  declare which version they need.

- Listings may use "for Bleep Patch" as described in the Trademark
  Policy. No other use of the Marks.
