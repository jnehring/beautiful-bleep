| Folder | What |
|---|---|
| [`specs/`](specs/) | The design specifications: the main spec ([`specs.md`](specs/specs.md)), one file per board module ([`modules/`](specs/modules/)), panels, bridges, cell plugins, system audio, [Bleep Script](specs/bleep-script.md) (concept) |
