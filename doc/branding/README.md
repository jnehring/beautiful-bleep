# Branding

Logo: two lowercase b's as a growing blip (small coral b, large cream b) on a dark badge.

| File | Use |
|---|---|
| `logo.svg` | Full badge. App icon, website, README |
| `logo-small.svg` | Heavier strokes, for 16 to 32 px (favicon, tab icon) |
| `logo-mark.svg` | Mark without badge, for light backgrounds |
| `logo-mono.svg` | One color (`currentColor`), for print, dark mode and watermarks |

Colors: badge `#1B1530`, coral `#FF6B5A`, cream `#FFF1DC`.
Corner radius of the badge is 58/256 (about 23%).
