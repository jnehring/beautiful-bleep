# VCA

A stereo amplifier. *Gain* starts at 0, so an envelope patched onto the Gain
knob opens it exactly as far as the envelope goes.

| Control | Range | What it does |
|---|---|---|
| Gain | 0 – 100 % | the level; patch an envelope here |
| Response | Linear, Exponential | Exponential makes fades sound even |

**Inputs:** *In L*, *In R* (with only *In L* patched, both sides get it).
**Outputs:** *Out L*, *Out R*.
