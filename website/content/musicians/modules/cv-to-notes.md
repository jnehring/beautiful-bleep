# CV to Notes

Turns pitch and gate into notes, so a sequencer or any mono source can play a
Voice Cell.

| Control | Range | What it does |
|---|---|---|
| Velocity | 0 – 100 % | velocity of the notes (a knob, so it can be modulated) |

**Inputs:** *Pitch* (1 V/oct), *Gate*. A rising gate starts a note; a pitch
change while the gate is high plays the new note legato.
**Outputs:** *Notes*.
