# Contribute to Bleep

These pages are for working on Beautiful Bleep itself, not on something that plugs
into it. To add a sound, write a [module](../modules/overview.md). To connect your
own plugin, use [Bleep Bus](../bleep-bus/quickstart.md).

| Change Bleep Play, the board in the browser | [Web](../web/bleep-play.md) |
| Set up my computer | [Developer setup](../setup/overview.md) |
| Build everything and cut a release | [Build and release](../setup/build-and-release.md) |
